## 同样 $5/月，两种方案差在哪

1 核 1GB 的两档都是 $5/月，2 核 2GB 的两档都是 $17/月，价差为零。区别全在带宽口径上。

**不限流量方案**按速率封顶，比如 5M 就是带宽上限 5Mbps，跑满一个月也不额外收费。流量再大也不加钱，但峰值被锁死，下载大文件或视频会明显吃紧。

**流量制方案**给的是更高的瞬时速率（10M、20M、30Mbps）加每月 1TB 的额度，超出部分按什么标准计费，公开页面没有逐项写明，下单前要在购物车或工单里问清楚。1TB 对普通网站来说很宽裕，只有做下载、图床、流媒体这类场景才需要盯住用量。

优化线路和国际线路的差别在回程路径上。优化线路对大陆方向的访问做了专门处理，延迟和丢包表现通常更好；国际线路更适合访客主要在海外、或者对大陆回程没有要求的场景。同价位下，如果访客以大陆和台湾本地为主，优先选优化线路。

## 下单前该问清的六件事

这几项在 LightLayer 的公开页面上没有全部写明，与其下单后才发现，不如先发一张工单。下面每一项都有其他台湾服务商的真实先例，说明这些问题不是杞人忧天。

**IPv4 给几个、IPv6 有没有。** 做 DNS、白名单、远程运维都依赖独立 IP，数量不够就得加购。有的服务商标配 5 个 IPv4，有的只给 1 个，差别很大。

**超流量怎么计费。** 流量制方案跑满 1TB 之后，是限速、停机还是按 GB 加收，规则不同，账单差别很大。

**备份和快照是否另收费。** 有些服务商把备份和快照做成两个独立加购项，而且明确写了快照不能替代备份：快照只能整机还原，取不回单个文件；备份空间至少要跟硬盘容量一样大。这些细节只看套餐页是看不到的。

**能不能降级。** 有服务商规定 CPU 和内存可以升降，硬盘只能加不能减。买大了想缩回来，不一定行得通。

**AUP 是否限制某些用途。** 台湾有服务商明文规定所有方案都不允许 VPN 相关应用，自用、公司内部使用、只当客户端三种情形全都算。做代理、跨境访问、流媒体分发的，下单前一定要确认。

**开通要多久。** 有的服务商付款后 5 分钟自动开通，有的要人工审核。急着上线的话这一项很关键。
